# 黑话速查（俗称 → 官方名）

玩家教程里 80% 的名词是俗称。写作时的处理原则：

> **标题与首次出现用官方名（附英文），后文用俗称**——这样既能被搜到，读起来又像人话。

**本文所有官方中文名均已通过 ESI `universe/types/{id}/?language=zh` 与 `universe/groups/{id}/?language=zh` 核实**（查法见 `官方数据源 - SDE 与 ESI.md`）。未核实的一律标「待核」。

---

## 一、使用规则

| 场景 | 写法 |
|---|---|
| 页面标题 | 官方名或通用说法（如「重型突击巡洋舰配置」），不写「HAC」「YST」|
| 正文首次出现 | `伊什塔级（Ishtar，俗称 YST）` |
| 正文后续 | 直接用俗称「YST」|
| 表格/数值 | 用官方名，避免同一表内混用 |
| 引用玩家原话 | 保留原俗称，必要时加括号注释 |

> ⚠️ 判断是否"已经够常用"：如果圈内 90% 的人只叫俗称（如「大航」「泡泡」），首次给官方名后就可以放心用俗称。

> ⚠️ **「点」是个多义词，写作时必须看语境**：
>
> | 语境 | 含义 | 例子 |
> |---|---|---|
> | 说位置/距离 | **作战位标**（战术书签）| 「在门 300km 拉个点」「按 ping 点跳过去」|
> | 说对敌舰动作 | **施加跃迁干扰**（断/频都可能）| 「我点住对面的 YST 了」「帮我点他一下」|
> | 说刷怪归属 | **报点**（登记异常空间所有权）| 「这个点我报了」|
>
> 作为**模块名**时：点 = 跃迁扰断器（长距、可被核心稳定器抵消），反跳 = 跃迁扰频器（近距、强制关停跃迁）。二者混写会让人白死；但口语说「点住」时，玩家通常只关心"他跳不走"，具体用哪种由距离决定。

## 四、行为与场景

| 俗称 | 含义 | 写作提示 |
|---|---|---|
| 刷怪 | 打异常空间/死亡空间里的 NPC | 首次出现写「刷异常空间（俗称刷怪）」|
| 报点 | 在频道登记自己所刷异常的所有权 | 联盟规则类，写清"报了点才能刷" |
| 拉点 | 把异常空间拉到自己名下/带人过去 | 语境不同含义不同，注明 |
| 过门 | 通过星门进入下一个星系 | 风险描述的重点场景 |
| 本地 | 本地频道人数 | 「看本地」= 判断有没有敌人 |
| 定向 / dscan | 定向扫描器 | 首次写「定向扫描（D-scan）」|
| 蹲站 | 停在空间站不出站 | 常用于伏击与反伏击 |
| 挂机 / 摆烂 | 低强度、低注意力的刷法 | 必须写清收益下降与风险上升 |
| 炸鱼 | 高效刷低难度目标（多指炸护卫/驱逐）| 贬义/自嘲色彩，正式标题避免 |
| 收菜 | 定期收割行星开发产物 | 与「种菜」配对 |
| 种菜 | 行星开发（PI）| 首次写「行星开发（俗称种菜）」|
| 挖坟 | 打遗迹/数据信号点 | 首次写「探索信号点（俗称挖坟）」|
| 打捞 | 回收残骸 | 与「垃圾」区分：垃圾=残骸里的物品 |
| 收割 / 单收 | 单人/小队猎杀生产船 | 与「反收割」相对 |
| 强暴 | 高安以优势火力强杀掠货 | 官方说法：高安强杀 |
| 空代 | **COSMOS 代理人**——代理人位于**太空中的复合体**（不是空间站内），故称"空代" | 首次出现写「COSMOS 代理人（俗称空代）」。任务只能做一次，奖励为剧情模块蓝图与势力声望 |
| 砸单 | 右键直接**卖给收购单**（砸在收单上）| 与「挂卖单」相对；写收益时说明是砸单价还是挂单价 |
| 挂单 / 收单 | 挂卖单（sell order）/ 收购单（buy order）| 交易类文档必须区分，两者价差常达 5–10% |
| 土路 | 不走星门、用虫洞/跳跃的运输路线 | 风险描述必备 |
| 跳桥 | 跳跃桥接（Jump Bridge）| 组织内部设施 |
| 诱导 | 跳跃诱导力场 | 旗舰投送 |
| 死亡空间 / 死亡 | 副本式空间（DED）| 与「远征」区分：远征是触发后的副本 |
| 远征 | 打异常触发的副本 | 首次写「远征（Expedition）」|

## 五、数值与度量

| 俗称 | 含义 | 规范写法 |
|---|---|---|
| 跳 | 星系间距离单位（1 跳 = 过 1 个星门）| 「7 跳」= 隔 7 个星门 |
| 有效 / EHP | 有效生命值（含抗性）| 首次写「有效生命值（EHP）」|
| DPS | 每秒伤害 | 统一大写 |
| 抗性 | 伤害抗性百分比 | 注明是"全抗"还是"单抗" |
| 每跳收益 | 每完成一次循环的收益 | 与"每小时"区分清楚 |
| m / b | 百万 / 十亿 ISK | 正式文档写 `100m ISK`、`1.2b ISK` 或全写 |
| LP | 忠诚点 | 兑换比例要写"每 LP 兑多少 ISK" |
| 单号 / 多开 | 单角色 / 多角色并行 | 收益必须注明是否多开 |

## 七、容易写错的对照

| 易错 | 正确 |
|---|---|
| 大航 = 航空母舰 | ❌ 大航 = **超级航母**；小航 = 航空母舰 |
| FAX = 后勤舰 | 官方是**战力辅助舰**，「后勤航」是俗称 |
| 泡泡 = 移动泡泡 | 泡泡 = 跃迁扰断力场发生器（拦截舰放的）；移动泡泡 = 机动跃迁扰断器（锚定的）|
| 点 = 反跳 | 作为模块：点 = 跃迁扰断器（长距）；反跳 = 跃迁扰频器（近距）。作为动作：「点住」= 施加跃迁干扰 |
| 「点」都指模块 | 「拉个点」是**位标**，「点住他」是**干扰**，「我报了这点」是**异常空间**——三义并存 |
| 空代 = 空间站代理人 | 空代 = **COSMOS 代理人**，位于太空复合体内，任务仅可完成一次 |
| 隐匿 = 隐形 | 模块叫**隐形装置**；「隐匿」也常指隐形特勤舰（Covert Ops）|
| 稳定器 | 「跃迁核心稳定器」防跳；「惯性稳定器」提灵活性——两者完全不同 |

## 八、维护方式

新增黑话时：

1. 先查 ESI 拿官方中文名（脚本见 `官方数据源 - SDE 与 ESI.md`）
2. 补进对应表格，标注英文名
3. 若属于"极易混淆"的一类，补进第七节
4. 无法核实的标「待核」，不要凭记忆填
