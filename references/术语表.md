# 术语表

写作时的术语统一基准。**原则：机制与术语首次出现给中英对照，后续用中文简称；产品名按官方写法；舰船昵称首次出现标注可检索的正式名。**

> 脱敏说明：已移除具体组织名、成员名与内部渠道名。组织相关的名称（军团名、联盟名、集结点星系）请在自己的版本中按实际情况填写。

> 舰船中文正式名请以 [EVE Ref 中文库](https://everef.net/zh/) 或游戏内客户端为准——社区昵称极多且有地域差异，不确定时宁可写正式名。

## 术语使用注意

1. **`ISK` 全大写**——早期材料中 `isk` 混用较多，新内容统一为 ISK。
2. **`Omega`、`Mumble`、`Outlook`、`Gmail` 按官方/产品大小写**，不写全大写。
3. **舰船昵称谨慎使用**：社区口语众多（如各类"小白""中白""钢板"型称呼），首次出现应给出可检索的正式名，避免新人无法对照。
4. **不确定的定义不写**：宁可标注「待确认」或省略，也不要给出可能错误的解释——机制术语解释错误会直接导致读者操作失误。
5. **中英混排加空格**：`使用 ISK 支付`、`检查 Mumble 语音设置`。
6. **组织专属术语单独维护**：军团名、联盟名、内部频道名、集结点星系、内部角色称呼（如"回收对接人""招新官"）属组织私有，建议在自己的分支/章节中维护，不混入通用术语表。
